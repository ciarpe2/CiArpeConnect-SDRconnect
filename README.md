# CiArpeConnect SDRconnect

CiArpeConnect SDRconnect e' una interfaccia sperimentale per SDRconnect pensata per ascolto SWL/HF, identificazione intelligente delle frequenze, consultazione database broadcast/utility e supporto operativo durante la ricezione.

## Versione

**1.0.0 Beta - prova 14 giorni**

Questa beta e' destinata ai test pubblici. Alcune funzioni possono essere incomplete o dipendere dalla configurazione locale di SDRconnect, del ricevitore e dell'audio di Windows.

## Funzioni principali

- Controllo frequenza e modi tramite SDRconnect.
- Waterfall e spectrum scope con scala regolabile.
- Frequency Intelligence con database broadcast, utility, radioamatori e decoder consigliati.
- Database aggiornabili da sorgenti SWL/HF.
- Registratore MP3.
- Scanner di banda HF.
- Supporto italiano/inglese.
- Pannelli SWL/HAM/Utility per sintonie rapide.

## Download

L'installer Windows si trova nella cartella:

`release/CiArpeConnect_1.0.0_Beta_Setup.exe`

## Requisiti

- Windows 10/11.
- SDRconnect installato e funzionante.
- Ricevitore SDR compatibile con SDRconnect.
- Python non richiesto per l'installer.
